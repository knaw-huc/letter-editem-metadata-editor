# Letter generic metadata editor
Generic (HuC) metadata application profile (and CMDI editor) for letters.
This repository is a fresh copy of the initial test repository: https://github.com/knaw-huc/hi-generic-letter-metadata-editor (archived).

Note May 29th, 2026: this was only a test repository. The idea was to test if a hybrid editor (with a Bio.xml profile using the eDiTem template for persons, plus a generic letter metadata editor could work for a researcher). The test didn't work for her purposes, but we keep the repository open, just in case someone else wants to test this approach.
